# Нестандартные ситуации, сообщения, эскалации, показатели

## Нестандартные ситуации

1. **Новинка без истории.** Единственный инструмент — аналоги. Подбирай по цене, категории, уровню бренда и целевой аудитории, а не только по типу продукта. Первая закупка — консервативно, 60% от прогноза по аналогам; еженедельные триггеры автопополнения.
2. **Вирусный всплеск в соцсетях.** Спрос подскакивает в 5–20 раз без предупреждения. Не гонись: пока цепочка поставок отреагирует (4–8 недель), волна пройдёт. Продавай с имеющихся запасов, введи правила распределения, чтобы одна точка не забрала всё, переждать. Базу пересматривай, только если повышенный спрос держится 4+ недели после пика.
3. **Срок поставки удвоился за ночь.** Сразу пересчитай страховой запас по новому сроку. Если он удвоился — из текущих остатков разрыв не закрыть: срочный заказ на разницу, частичные отгрузки, поиск второго поставщика. Предупреди ассортимент/маркетинг, что уровень сервиса временно упадёт.
4. **Каннибализация от незапланированной акции** (конкурента или соседнего отдела). Прогноз окажется завышенным. Лови рано по ежедневным продажам (слом рисунка), вручную снижай прогноз, по возможности переноси входящие поставки.
5. **Смена режима спроса.** Стабильно-сезонная позиция вдруг стала трендовой или хаотичной — после смены рецептуры, упаковки, появления или ухода конкурента. Старая модель ломается молча. Следи за сигналом отслеживания еженедельно: два периода подряд за ±4 → перевыбор метода.
6. **«Фантомные» остатки.** Учётная система показывает 200 единиц, по факту 40. Все решения на этих данных неверны. Подозревай, когда уровень сервиса падает при «достаточных» остатках. Проводи выборочную инвентаризацию по позициям с необъяснимым дефицитом.
7. **Минимальная партия поставщика больше нужного.** Расчёт говорит 150, минимум поставщика 500. Варианты: собрать заказ с другими позициями этого поставщика до денежного минимума; договориться о меньшей партии; принять излишек, если хранение дешевле альтернативного поставщика.
8. **Сдвиг праздников по календарю.** Когда ключевой праздник «переезжает» между неделями или месяцами, сравнение неделя к неделе ломается. Выравнивай прогноз по «неделям относительно праздника», а не по календарным неделям.

## Тон сообщений (шаблоны)

- **Плановый дозаказ поставщику:** коротко, по делу, со ссылкой на номер заказа. «Заказ №___ к поставке на неделе __.__ по согласованному графику».
- **Эскалация срока поставки:** твёрдо, с фактами и последствиями для бизнеса. «По нашим данным, срок поставки вырос с __ до __ дней за последние __ недель. Это привело к __ случаям дефицита. Просим план исправления до __».
- **Внутренний алерт о дефиците:** срочно, с действиями и оценкой потерь. Начинай с последствий для гостя/клиента, а не с метрики запаса. «Позиция __ закончится в __ точках к __. Оценка потерянных продаж: __. Предлагаем: [срочная поставка / перераспределение / замена]».
- **Рекомендация об уценке:** с данными и влиянием на маржу. Не «мы закупили слишком много», а «темп продаж требует ценового шага, чтобы выйти на целевую маржу».
- **Прогноз под акцию:** структурно — база, прирост и провал после акции отдельно, с допущениями и диапазоном уверенности.
- **Допущения по новинке:** каждое допущение записано, чтобы его можно было проверить на разборе: аналоги, цена, число точек, отсутствие конкурентных запусков в окне.

Любое сообщение поставщику или команде — только после явного подтверждения пользователя.

## Автоматические триггеры эскалации

| Триггер | Действие | Срок |
|---|---|---|
| Прогноз дефицита по A-позиции в пределах 7 дней | Сообщить руководителю планирования и ответственному за категорию | В течение 4 часов |
| Поставщик подтвердил рост срока поставки > 25% | Сообщить руководителю цепочки поставок; пересчитать все открытые заказы | В течение 1 рабочего дня |
| Промах прогноза акции > 40% (в любую сторону) | Разбор после акции с маркетингом и поставщиком | В течение недели после акции |
| Излишек > 26 недель запаса по A/B-позиции | Рекомендация об уценке | В течение недели после обнаружения |
| Смещение прогноза за ±10% 4 недели подряд | Пересмотр и перенастройка модели | В течение 2 недель |
| Продажи новинки < 40% плана через 4 недели | Пересмотр ассортимента | В течение недели |
| Уровень сервиса < 90% по любой категории | Поиск причины и план исправления | В течение 48 часов |

Цепочка: планировщик → руководитель планирования (24 часа) → директор по планированию цепочки поставок (48 часов) → руководитель цепочки поставок (72+ часа или любой дефицит A-позиции у ключевого клиента). В небольшой команде замени уровни на реальных ответственных.

## Показатели (еженедельно, тренд помесячно)

| Показатель | Цель | Красный флаг |
|---|---|---|
| WMAPE | < 25% | > 35% |
| Смещение прогноза | ±5% | > ±10% 4+ недели |
| Наличие A-позиций | > 97% | < 94% |
| Наличие всех позиций | > 95% | < 92% |
| Недель запаса (в целом) | 4–8 | > 12 или < 3 |
| Излишки (> 26 недель запаса) | < 5% позиций | > 10% позиций |
| Мёртвый запас (нет продаж 13+ недель) | < 2% позиций | > 5% позиций |
| Выполнение заказов поставщиками | > 95% | < 90% |
| Точность прогноза акций (WMAPE) | < 35% | > 50% |

Ориентиры — из исходной методики для розничной сети; для общепита и скоропорта сверяй со своими нормами и сроками годности.

Храни разборы промахов по акциям, задержкам поставщиков и ручным поправкам рядом с планом, чтобы нестандартные ситуации превращались в правила.
