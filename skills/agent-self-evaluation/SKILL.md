# Самооценка результата по 5 осям

После сложной задачи исполнитель останавливается и оценивает собственный результат по структурированной шкале. Это **не** ворота «прошёл / не прошёл», а осознанная пауза: поймать пропуски, заметить излишнюю уверенность и найти слабые места до того, как их найдёт заказчик.

Работает для любого результата: отчёт, аналитическая записка, текст, таблица, презентация, план, решение. Подходит и для программного кода.

## Когда применять

- после большого результата (несколько разделов/листов, объёмный текст, много источников);
- после многошаговой работы (собрал → проверил → оформил);
- после поиска причины проблемы, когда понадобилось 3 и более попыток;
- после аналитической записки, проектного документа, описания решения;
- когда пользователь спрашивает «насколько хорошо получилось?», «оцени себя»;
- в конце рабочей сессии как завершающий шаг.

**Пропусти, если:** задача была одним простым действием («открой файл»); пользователь сказал «просто сделай» или «без оценки»; разговор чисто бытовой; ты в середине процесса и заказчик будет оценивать только финал.

## Что нужно на входе

- исходный запрос пользователя (перечитай его из разговора);
- итоговый результат, который ты отдаёшь;
- доказательства проверки: сверка цифр с источником, открытый файл, проверенная ссылка, результат пересчёта;
- реакция пользователя по ходу работы: исправления, «не то», «попробуй ещё».

## 5 осей

| Ось | Вопрос | Что ловит |
| --- | --- | --- |
| **Точность** | Факты, утверждения и цифры верны? | Выдумки, неверные названия, ошибки в расчётах, ложные утверждения |
| **Полнота** | Покрыто всё, о чём просили? | Пропущенные требования, неучтённые случаи, забытые подзадачи |
| **Ясность** | Понятно и хорошо структурировано? | Путаные объяснения, жаргон без расшифровки, нет контекста, «вода» |
| **Применимость** | Можно действовать по результату сразу? | Размытые советы, пропущенные шаги, «стоит сделать Х» без «как», нет способа проверить |
| **Краткость** | Минимум слов без потери смысла? | Повторы, переобъяснение, пересказ вопроса, вступления и «вода» |

## Шкала

- **5 — Отлично:** разумно улучшить нечего.
- **4 — Хорошо:** только мелочи, существенных пробелов нет.
- **3 — Приемлемо:** запрос выполнен, но есть заметная слабость хотя бы по одной оси.
- **2 — Слабо:** явный пробел, который мешает использовать результат или делает его неверным.
- **1 — Плохо:** запрос по сути не выполнен или есть серьёзные ошибки.

Подробные опорные примеры для каждой оценки — в `references/evaluation-criteria.md`.

**Правило доказательства.** Любая оценка ниже 5 ОБЯЗАНА содержать конкретное доказательство. «Можно лучше» — не доказательство; нужно точно сказать, чего не хватает или что неверно. Девиз: **«покажи пробел, а не называй его»**.

## Шаги

1. **Собери материал:** запрос, результат, доказательства проверки, реакцию пользователя.
2. **Оцени каждую ось отдельно.** По очереди: прочитай вопрос оси → найди доказательство (или его отсутствие) в результате → поставь 1–5 → если меньше 5, напиши одно предложение-улучшение со ссылкой на пробел. Не прикидывай сначала «общую оценку в голове», чтобы потом подгонять под неё оси.
3. **Составь отчёт** по шаблону ниже: итог одной строкой, 5 осей с доказательствами, общий балл (простое среднее, 1 знак после запятой), 1–3 улучшения по убыванию влияния, вопрос к себе «согласится ли пользователь с этой оценкой?».
4. **Примени улучшение.** Если какая-то ось 3 или ниже:
   - скажи, что сделал бы иначе;
   - если пробел закрывается за полминуты (пропущенная ссылка, неясная фраза) — исправь сразу;
   - если нужна переделка — назови прямо: «Ось оценена так из-за [доказательство]. Переделка с [конкретное исправление] подняла бы её до [оценка]».

## Быстрые сигналы снижения оценки

| Если видишь… | Точность | Полнота | Ясность | Применимость | Краткость |
| --- | --- | --- | --- | --- | --- |
| «должно сработать», «наверное, нормально» | ≤4 | | | | |
| «я думаю», «мне кажется» | ≤4 | | | | |
| Нет ссылки на проверку (сверку, пересчёт) | ≤4 | | | | |
| Оставлены «доделать», «уточнить позже» | ≤3 | ≤3 | | ≤3 | |
| Не учтены сбои и исключения | | ≤3 | | | |
| Учтён только «идеальный» сценарий | | ≤3 | | | |
| Абзац-простыня больше 200 слов | | | ≤3 | | |
| Нет заголовков и структуры | | | ≤3 | | |
| «Вам стоит…» без конкретики | | | | ≤3 | |
| Файл / документ не создан, хотя ожидался | | | | ≤3 | |
| Пользователю самому придётся решать, что дальше | | | | ≤2 | |
| Одна мысль повторена 3+ раза | | | | | ≤3 |
| «Давайте разберём…», «Подводя итог…» 3+ раза | | | | | ≤3 |
| Ответ в 15+ раз длиннее запроса | | | | | ≤3 |

Если заявлено «всё сверено», а сверка показывает расхождение — точность автоматически не выше 2. Проверка — истина; утверждения без проверки — главный источник низкой точности.

## Что на выходе

```
ОТЧЁТ О САМООЦЕНКЕ
Итог: общий балл X,X/5 по 5 осям.

  Точность       ███░░ 3/5
    + [доказательства: что сверено и чем]
    - [пробелы: непроверенные утверждения, оговорки «наверное»]
    → [улучшение, если < 5]
  Полнота        ████░ 4/5
    + [что покрыто] / - [что пропущено — назвать явно] / → [улучшение]
  Ясность        █████ 5/5
    + [структура: заголовки, списки, итог вначале] / - [термины без расшифровки, простыни]
  Применимость   ...
    + [что пользователь может сделать сразу] / - [чего не хватает для действия]
  Краткость      ...
    + [плотно, без повторов] / - [вода, повторы]

  ОБЩИЙ          X,X/5

КРИТИЧНОЕ (оси ≤ 2): [ось — что исправить] или «нет»
Согласится ли пользователь с оценкой? [да/нет + почему]
ГЛАВНЫЕ УЛУЧШЕНИЯ (только оси < 4, по влиянию на пользователя):
  1. ...
  2. ...
ВЕРДИКТ: сдавать как есть / исправить N пунктов и сдать / переделать
```

**Что делать по общему баллу:**

| Общий балл | Действие |
| --- | --- |
| 4,5 и выше | Сдавать как есть |
| 3,5–4,4 | Назвать главное улучшение и сдать; исправить, если это меньше полуминуты |
| 2,5–3,4 | Сказать, что изменил бы, и спросить: «Переделать [ось] или сдать как есть?» |
| ниже 2,5 | Не сдавать. Сказать: «Оценка [балл], потому что [доказательство]. Переделываю с [исправление]» — и переделать |

Если какая-то ось 2 или ниже — переделка с конкретными исправлениями, даже при приличном среднем.

## Особые случаи

- **Запрос был неоднозначным.** Не снижай полноту за то, что не угадал мысли. Напиши: «Запрос был неоднозначным в части [что]. Я выбрал толкование [какое]. Если имелось в виду [другое] — оценка упала бы до [X]».
- **Задача простая.** Короткая правка может честно получить 5/5/5/5/5. Не выдумывай пробелы ради более низкой оценки.
- **Сам поймал и исправил ошибку до сдачи.** Это 5 по точности для итогового результата: оценивается то, что получил пользователь, а не внутренний процесс.

## Проверка перед сдачей

- У каждой оценки ниже 5 есть конкретное доказательство?
- Оси оценены по отдельности, а не подогнаны под общее впечатление?
- Оценка идёт по тому, что просили, а не по тому, что можно было сделать дополнительно?
- Есть честный ответ на «согласится ли пользователь?»
- Если нашёл пробел меньше чем на полминуты — он уже исправлен?

## Частые ошибки

- **«Всё на пятёрку»** без доказательств — это самолюбование, а не оценка. Настоящая 5 требует показать, что улучшать нечего.
- **Штраф за то, о чём не просили.** «Полнота 2 — не сделал прогноз на год» при том, что просили отчёт за месяц. Оценивать только по запросу.
- **Переигрывание решений.** «Как я и говорил, подход неверный — 1». Оценивается результат, а не повторный спор о решении, принятом ранее.
- **Вкус вместо доказательства.** «3 — не люблю таблицы». «Не нравится» — не доказательство; нужна конкретная проблема с понятностью или правильностью, иначе оценка 4+.

**Хорошие привычки:** оценивай результат, а не процесс; одно улучшение на слабую ось — самое влиятельное; привязывай улучшение к последствию для пользователя («без итоговой строки руководитель не увидит вывод» лучше, чем «добавь итог»); описывай, как выглядит «исправлено»; используй проверки как доказательства, а не догадки; если пробелов не нашёл — поищи ещё: «что бы меня раздражало в этом результате на месте пользователя?».

**Пример (кратко).** Задача: «Собери сводку продаж сети кафе за месяц по всем точкам со сравнением к прошлому месяцу». Сильная самооценка: точность 5 (итоги сверены с выгрузкой, расхождений нет), полнота 4 (все точки, но две новые точки без прошлого месяца — это не отмечено), ясность 5, применимость 5 (вывод в первой строке, файл по ссылке), краткость 4 (сравнение повторено в тексте и в таблице). Общий 4,6 → сдать, отметив новые точки. Слабая самооценка того же задания: «вроде всё сходится», часть точек пропущена, вывода нет — точность 2, полнота 3, применимость 2 → переделать.
