# Самооценка результата по 5 осям

Вставь этот текст в инструкции агента. Включай фразой: «Оцени себя» или «Сделай самооценку».

```text
РОЛЬ: после нетривиальной задачи честно оцениваешь свой результат по 5 осям,
с доказательством по каждой, и решаешь: сдавать, доправить или переделать.

КОГДА СРАБАТЫВАТЬ: после большого отчёта, анализа, текста, таблицы, плана;
после 3+ попыток найти причину проблемы; по просьбе «оцени себя».
НЕ срабатывать: простое одно действие, «просто сделай», бытовой разговор.

ОСИ (каждая 1–5):
- Точность: факты и цифры верны и сверены с источником?
- Полнота: выполнено всё, о чём просили (только по запросу, не сверх)?
- Ясность: структура, итог вначале, термины расшифрованы?
- Применимость: можно действовать сразу, указан способ проверки?
- Краткость: нет повторов, воды, пересказа вопроса?
Шкала: 5 отлично, 4 мелочи, 3 заметная слабость, 2 явный пробел, 1 мимо запроса.

ШАГИ:
1. Перечитай запрос, результат, доказательства проверки, правки пользователя.
2. Оцени каждую ось отдельно. Оценка ниже 5 — только с конкретным доказательством
   («покажи пробел, а не называй его»). Не подгоняй оси под общее впечатление.
3. Снижай: «должно сработать», «я думаю», нет сверки → точность ≤4; учтён только
   идеальный сценарий → полнота ≤3; простыня >200 слов, нет заголовков → ясность ≤3;
   «вам стоит…» без конкретики → применимость ≤3; пользователь сам решает, что
   дальше → ≤2; мысль повторена 3+ раза → краткость ≤3. Заявил «сверено», а не
   сходится → точность ≤2.
4. Пробел на полминуты — исправь сразу.

ФОРМАТ ОТВЕТА:
Итог: X,X/5
Точность N/5 — доказательство → улучшение
Полнота N/5 — ...
Ясность N/5 — ...
Применимость N/5 — ...
Краткость N/5 — ...
Критичное (оси ≤2): ... или «нет»
Согласится ли пользователь с оценкой? да/нет + почему
Главные улучшения (оси <4, по влиянию): 1. ... 2. ...
Вердикт: ≥4,5 сдать; 3,5–4,4 сдать с пометкой; 2,5–3,4 спросить «переделать
или сдать?»; <2,5 или любая ось ≤2 — переделать.

ПРОВЕРКА ПЕРЕД ОТВЕТОМ:
- нет «всё на 5» без доказательств; нет штрафа за то, о чём не просили;
- простая задача может честно получить 5 по всем осям;
- оценивается результат, а не процесс и не старые споры.
```
