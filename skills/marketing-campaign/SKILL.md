# Маркетинговая кампания: от исследования до контент-календаря

Планировать и выпускать кампании, которые приводят к действию, а не просто «выходят в свет».

## Когда применять

- запуск продукта, услуги, нового блюда, акции, открытия точки, предложения для франчайзи;
- полный набор контента из одного брифа продукта;
- нужно определить позиционирование и угол кампании до того, как писать тексты;
- координация нескольких типов контента в разных каналах;
- проверка готовых текстов на «продающесть» и единый голос бренда.

## Непреложные правила

1. Сначала позиционирование, потом тексты. Все тексты вытекают из угла кампании.
2. Сначала изучить аудиторию, а не предполагать, что знаешь её язык и страхи.
3. У каждого материала — одна понятная задача в общей арке кампании.
4. Конкретика важнее прилагательных — в любом формате и канале.
5. Один голос во всех каналах и материалах.
6. Ни один текст не выходит без «Проверки перед сдачей».

## Что нужно на входе

- бриф продукта/предложения: что это, для кого, цена или условия, сроки;
- реальные данные и доказательства (отзывы, цифры, факты) — только от пользователя, не выдумывать;
- список каналов кампании;
- образцы голоса бренда или готовый профиль голоса.

Если у агента есть поиск в интернете — использовать его для исследования аудитории и конкурентов; если нет — попросить пользователя дать ссылки, отзывы клиентов, примеры конкурентов.

## Шаги

### Фаза 1. Исследование

- портрет целевой аудитории: какую «работу» человек нанимает продукт сделать, его страхи, его слова, какими альтернативами он пользуется сейчас;
- 3+ прямых или смежных конкурента: позиционирование, пробелы, слабые места в их сообщениях;
- 1–3 инсайта об аудитории, на которых будет стоять угол кампании.

**Результат фазы:** короткий бриф исследования (портрет аудитории + сводка по конкурентам + ключевые инсайты).

### Фаза 2. Позиционирование

- главная выгода — одно предложение, без списка функций и без жаргона;
- формула позиционирования: «[Продукт] помогает [аудитории] [достичь результата] за счёт [механизма]»;
- угол кампании — конкретное напряжение, инсайт или момент, в котором живёт вся кампания;
- профиль тона — зафиксировать до написания (для устойчивого результата — собрать профиль голоса по реальным текстам, навык «голос бренда»).

**Не писать ни одного текста, пока позиционирование и угол не одобрены пользователем.**

### Фаза 3. Производство контента

В таком порядке — каждый слой опирается на предыдущий:

1. **Тексты посадочной страницы** — все блоки: первый экран, проблема, решение, преимущества, как это работает, доказательства, призыв к действию.
2. **Цепочка писем** — у каждого письма одна задача; арка: проблема → обучение → обострение → решение → доказательство → срочность → финальный призыв.
3. **Посты в соцсетях** — под формат каждой площадки (навык «контент-движок»); деловая соцсеть и короткая лента — разные форматы, а не один текст другого размера.
4. **Сценарии коротких видео** — разбиты по таймкодам; написаны для экрана и слуха, а не для чтения.
5. **Варианты рекламных объявлений** — 3–4 варианта, проверяющие разные углы или сегменты аудитории.
6. **Контент-календарь** — по дням: канал, тип материала, время, зависимости.

### Фаза 4. Проверка

Каждый материал прогнать через:
- **тест 5 секунд** для первого экрана и заголовков: за 5 секунд ясно, для кого, что делает и почему действовать сейчас;
- **аудит призывов к действию**: один на материал, конкретный, заслуженный — не требование;
- **проверку тона** между всеми каналами;
- **аудит утверждений**: каждое конкретное и доказуемое;
- **сквозную сверку**: обещания в рекламе совпадают с посадочной страницей; тема письма совпадает с его содержанием.

Для независимой проверки можно открыть отдельный чат или поручить роль «проверяющего», который не видел, как писались тексты, и дать ему только итог и этот список.

## Что на выходе

Полная кампания:

1. **Бриф позиционирования** — угол, главная выгода, профиль тона.
2. **Тексты посадочной страницы** — первый экран, проблема, решение, преимущества, как это работает, доказательства, призыв.
3. **Цепочка писем** — тема + прехедер (строка-превью) + текст + призыв для каждого письма, с пометкой дня и задачи.
4. **Посты для деловой соцсети** — 3+ «родных» поста с разными углами.
5. **Посты для короткой ленты / мессенджер-канала** — 5+ отдельных постов и 1 серия.
6. **Сценарии коротких видео** — 2+ сценария по таймкодам с пометками для видеоряда.
7. **Варианты рекламы** — короткий заголовок / длинный заголовок / текст для каждого варианта.
8. **Контент-календарь** — по дням: канал, тип, время, зависимости.
9. **Итоги проверки** — найденные проблемы и открытые вопросы до запуска.

Запуск рекламы, отправка писем, публикация постов, любые расходы бюджета — только после явного подтверждения пользователя.

## Проверка перед сдачей

- все материалы звучат как один автор;
- не осталось пустых превосходных степеней и прилагательных-заполнителей;
- каждый призыв конкретный и заслуженный (никогда «узнать больше» или «нажмите здесь»);
- тексты не дублируются дословно между площадками;
- первый экран проходит тест 5 секунд;
- темы писем совпадают с содержанием (без «приманки и подмены»);
- обещания в рекламе в точности совпадают с посадочной страницей;
- ни один текст нельзя без изменений перенести на любой другой продукт этой категории.

## Частые ошибки (удалить и переписать)

- «меняющий правила игры», «революционный», «мирового уровня», «инновационный»;
- «В условиях современной конкуренции…»;
- фальшивая срочность без реального дедлайна;
- пустое социальное доказательство без конкретики («нам доверяют тысячи»);
- общие призывы («узнать больше», «подробнее», «нажмите здесь»);
- текст, который можно вставить в кампанию конкурента без изменений.
