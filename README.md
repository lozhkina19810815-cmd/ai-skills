# Универсальные скиллы для ИИ-агентов

24 готовые инструкции («скиллы») для ИИ-агентов. С ними агент выполняет типовые рабочие задачи по проверенной методике: исследует рынок, разбирает конкурентов, пишет контент голосом бренда, проверяет результат перед сдачей.

Скиллы взяты из открытого репозитория [ECC](https://github.com/affaan-m/ECC), переведены на русский и переписаны так, чтобы работать в **любом** агенте: Claude, ChatGPT, DeepSeek, GigaChat, Cursor, Codex. Из 293 скиллов ECC сюда попали 24, полезные не только разработчикам. Остальные про программирование.

## Что такое скилл

Скилл — это инструкция для агента: когда её включать, какие данные нужны на входе, какие шаги сделать, в каком виде сдать результат и как его проверить. Агент перестаёт импровизировать и работает по одной методике у любого человека.

В каждой папке `skills/<название>/` лежат:

- **`SKILL.md`** — полная версия в стандартном формате Agent Skills: описание, шаги, шаблоны, частые ошибки;
- **`PROMPT.md`** — короткая версия (до 50 строк), готовая для вставки в инструкции чат-агента;
- `references/` (у некоторых) — шаблоны и справочные материалы к скиллу.

## Как пользоваться

**Способ 1. Любой чат: ChatGPT, DeepSeek, GigaChat, Claude.**
Откройте `PROMPT.md` нужного скилла и скопируйте блок текста в инструкции агента. В ChatGPT это «Настроить ChatGPT» или инструкции своего GPT / проекта, в Claude — инструкции проекта, в DeepSeek и других — системный промпт. Дальше включайте скилл фразой, которая указана в начале `PROMPT.md`.

**Способ 2. Разовая задача.**
Прикрепите `SKILL.md` к сообщению и напишите: «Работай по этой инструкции. Задача: …».

**Способ 3. Агенты с поддержкой скиллов: Claude Code, Codex, Cursor и другие.**
Положите папку скилла целиком в папку скиллов агента. Для Claude Code это `.claude/skills/` в проекте или `~/.claude/skills/` для всех проектов. Для остальных агентов путь смотрите в их документации. Агент сам включит скилл, когда задача подходит под описание.

Скачать всё сразу: зелёная кнопка **Code → Download ZIP** вверху страницы.

## Что изменено относительно оригинала

- Перевод на русский; примеры заменены на общие (сеть кафе, франшиза, интернет-магазин).
- Убрано всё, что работало только в Claude Code: вызовы инструментов, хуки, команды, пути к файлам, платные внешние сервисы. Вместо этого формулировки вида «если у агента есть поиск в интернете — ищи сам, если нет — попроси источники».
- Любое действие, которое отправляет, публикует, платит или удаляет, — только после явного подтверждения пользователя.
- Методика (шаги, шкалы, чек-листы, шаблоны) сохранена.

**Почему не ставить ECC целиком.** Его установщик запускает код на компьютере, хуки встают на каждое действие агента и записывают все запросы в файл, есть автообновление из интернета. Здесь собраны только тексты инструкций: ничего не устанавливается и не запускается.
